✨ MidnightMap V2
MidnightMap started as a simple project to clean up the default World of Warcraft minimap.

V2 has grown into something much more.

Underneath the interface is a modular runtime with dedicated systems for appearance, themes, movement, visibility, minimap elements, zoom, calendar integration and addon-button management.

The result is a minimap that remains lightweight while offering considerably deeper customization.

🔍 Mousewheel Zoom
Use the mouse wheel directly over the minimap to zoom in and out.

Auto Zoom Reset
Optionally let MidnightMap automatically restore your normal zoom level after a configurable delay.

No more accidentally leaving the minimap zoomed all the way in.

📅 Smart Calendar
MidnightMap can keep the Calendar button hidden during normal gameplay while automatically making it available when you have a pending calendar invitation.

Clean when you don't need it.

Visible when you do.

🧩 Button Manager V2
MidnightMap includes a dedicated system for managing third-party addon minimap buttons.

The Button Manager can:

Collect them into a clean button bar
Reposition the bar
Change button size
Lock the bar
Auto-hide the bar
Exclude selected buttons
The V2 compatibility layer also includes special handling for protected, forbidden and masked textures to improve compatibility with modern WoW addons.

❤️ About MidnightMap
MidnightMap is a personal project I've wanted to create since I started playing World of Warcraft nearly 20 years ago.

What began as an idea for a cleaner minimap has gradually turned into one of my favorite projects to work on.

V2 represents the direction I always wanted for it: lightweight underneath, deeply customizable when you want it, and designed to feel like a natural part of World of Warcraft.
